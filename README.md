# 使用 GitHub Pages 免费搭建一个属于自己的个人博客

## 前言

我知道，对于许多程序员和技术大佬来说，搭建一个网站或网页可能是一件很轻松的事情。写代码、部署项目、配置服务器，这些操作对于有经验的人来说或许早已习以为常。

而 GitHub 本身就是一个汇聚了许多优秀开发者的平台。相比那些复杂的项目和高深的技术，我今天想分享的内容可能显得有些微不足道。

不过，换个角度想想：**即使只是拥有一个免费的个人博客，用来展示自己的文字、记录生活、分享知识，也未尝不是一件不错的事情，对吧？**

我们不一定需要开发一个功能复杂的网站，也不一定需要购买服务器、注册域名。对于只是想拥有一个个人展示页面的人来说，GitHub Pages 就是一个值得尝试的选择。

## 一、什么是 GitHub Pages？

GitHub Pages 是 GitHub 提供的一项静态网站托管服务，可以将仓库中的网页文件发布到互联网上，让其他人通过网址访问。

简单来说，你可以把它理解为：

- **免费托管：** 不需要单独购买服务器来托管静态网页。
- **个人展示：** 可以用来制作个人博客、个人主页、项目介绍页等。
- **支持 Markdown：** 可以使用 `.md` 文件编写文章，再通过静态网站生成器将文章转换为网页。
- **方便维护：** 通过 GitHub 仓库管理文件，修改内容后重新发布即可。

当然，它主要用于静态网站。如果需要用户登录、数据库、动态业务处理等功能，就可能需要额外的服务或后端程序。

### 2. 创建一个仓库

创建一个新的 Repository（仓库），用于存放网站文件。

仓库名称可以根据自己的需求设置。如果想创建个人主页，也可以研究 GitHub Pages 对个人站点仓库命名的要求。

### 3. 准备网页文件

最基础的静态网页通常由 HTML、CSS 等文件组成。

例如，可以创建一个 `index.html` 文件，作为网站的首页。如果想制作博客，也可以使用 Jekyll 等静态网站生成器，将 Markdown 文章转换为网页。

### 4. 开启 GitHub Pages

进入仓库的 Settings（设置），找到 Pages 页面，根据页面提供的选项配置发布来源。

完成配置并等待部署成功后，GitHub 就会提供相应的网站访问地址。

至此，一个简单的静态网页就可以发布到互联网上了。

## 三、为什么需要一个个人博客？

也许有人会觉得，现在已经有很多成熟的平台可以发布文章，为什么还要自己搭建博客？
这件事的意义不一定在于技术有多么复杂，而在于拥有一个可以按照自己想法整理和展示内容的空间。

是一个记录学习过程的地方，可以是一个分享技术经验的窗口，也可以只是一个存放个人想法的小角落。
